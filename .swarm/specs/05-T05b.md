# 05 — T05b Tauri autostart + documented .exe build

## Goal
Add Windows login autostart via tauri-plugin-autostart with a Settings toggle (desktop only), and document how `npm run tauri build` produces the Windows installers.

## Files to change
- `package.json` — add dependency `"@tauri-apps/plugin-autostart": "^2.7.0"` (JS API; run `npm install` so typecheck resolves it).
- `src-tauri/Cargo.toml` — add `tauri-plugin-autostart = "2"` (plugin needs Rust ≥ 1.90; note it in README).
- `src-tauri/src/lib.rs` — register `.plugin(tauri_plugin_autostart::init(tauri_plugin_autostart::MacosLauncher::LaunchAgent, None))` on the builder before `.run(...)`.
- `src-tauri/capabilities/default.json` — add `"autostart:default"` to `permissions` (that set grants allow-enable / allow-disable / allow-is-enabled).
- `src/lib/autostart.ts` — NEW: `isAutostartAvailable()`, `autostartLabel(enabled, busy)`, `autostartError(e)`, `loadAutostart()`, `setAutostart(on)`.
- `src/lib/autostart.test.ts` — NEW (tests).
- `src/components/SettingsView.tsx` — new "Desktop" Panel between Preferences and Data, with the toggle; render only when `isNative`.
- `README.md` — "Desktop / Windows .exe" notes under Native desktop + update the Scripts table row.

## Data / API shape
`src/lib/autostart.ts` imports `isTauri` from `../storage`. `isAutostartAvailable() = isTauri`.
`loadAutostart()` returns `false` immediately when not Tauri; else `const { isEnabled } = await import("@tauri-apps/plugin-autostart"); return isEnabled();`. `setAutostart(on)` does the same with `enable()` / `disable()`. Keep the dynamic import so browser mode never executes plugin code.
Pure helpers: `autostartLabel(enabled: boolean, busy: boolean): "Checking…" | "On" | "Off"` (busy wins); `autostartError(e: unknown): string` → "This desktop build does not support autostart" for non-Tauri / plugin-missing, else `e instanceof Error ? e.message : String(e)`.

## UI/UX
- Panel: reuse the existing `Panel` pattern in `SettingsView.tsx` (`panel p-5`, header well `h-10 w-10 rounded-xl bg-accent/15 text-accent` with lucide `Power`, title 14px semibold text-ink, description 12px text-muted "Start ToDoMate when you sign in."). Render only when `isNative` is true — no dead toggle in browser mode.
- Row: label 14px "Open at login"; trailing switch: 44×28px track (`rounded-full bg-ink/10`, on → `bg-accent`), 22px knob (`translate-x-4` when on), `role="switch"`, `aria-checked`, `aria-label="Open at login"`, `focus-visible:ring-2 focus-visible:ring-accent`. Status text 12px `text-faint` from `autostartLabel`, right-aligned.
- States: on mount `busy = true`, switch disabled, status "Checking…"; after `loadAutostart()` show On/Off; on click set busy until `setAutostart` resolves; on failure restore the previous value, show inline 12px `text-rose` message from `autostartError` and `notify(message, "error")`; on success `notify("Open at login enabled"/"disabled")`. No raw colours — existing theme tokens only.
- Narrow screens: Panel spans the existing `max-w-3xl`; row uses `flex items-center justify-between gap-3`, switch stays a 44px touch target. Keyboard: Tab reaches the switch, Space/Enter toggles (native button), focus ring as above. No new screens or routes.

## Edge cases / must NOT change
- Browser dev mode: no panel, no plugin import executed, no console errors.
- A Tauri build missing the Rust plugin: `autostartError` message shown, toggle returns to previous state, app keeps running.
- Toggling never restarts/closes the app; state is read from the OS on each mount — do NOT persist a duplicate flag in `AppData.settings`.
- Do NOT change the theme, other settings panels, `bundle.targets` (keep `"all"`), the storage adapter, or web build scripts.

## Docs
README, under Native desktop:
```
npm install
npm run tauri build     # Windows: MSI + NSIS .exe installers
```
Installers land in `src-tauri/target/release/bundle/msi/` and `src-tauri/target/release/bundle/nsis/`; autostart requires Rust ≥ 1.90. Update the Scripts table row for `npm run tauri build` to "Build Windows .exe installers (MSI + NSIS) under src-tauri/target/release/bundle/". Mention Settings → Desktop → "Open at login" works only in the desktop build.
