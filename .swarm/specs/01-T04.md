# 01 — T04 Habits setup screen

## Goal
Give habits a dedicated full-screen setup page (create / edit / archive, schedule, category). The add-task flow becomes tasks-only; ghost habit rows on the Day page stay exactly as they are.

## Files to change
- `src/domain/habits.ts` — add pure `partitionHabits(habits)` selector.
- `src/domain/habits.test.ts` — NEW (tests).
- `src/state/store.tsx` — add `archiveHabit(id, archived = true)` to `Actions`; `deleteHabit(id)` delegates to it. No schema change: `deletedAt` IS the archive flag.
- `src/components/HabitEditor.tsx` — keep the `HabitEditor` create/edit bottom sheet; DELETE the `HabitsList` export (the list moves to the new view). Its trash button calls `archiveHabit(habit.id, true)`.
- `src/components/HabitsView.tsx` — NEW: the setup screen content.
- `src/components/DayView.tsx` — add `"habits"` to `MenuPage`; add Habits to the ☰ menu (Flame icon, between Categories and Library); remove the "Add as habit…" item and the `onAddHabit` prop/state path from `CategorySection`; stop rendering `<HabitsList>`; ghost rows keep accept + edit-sheet behaviour.
- `src/components/AppShell.tsx` — `TITLES.habits = "Habits"`; render `<HabitsView date={todayISO()} />` for the habits page (no new route).

## Data / API shape
`Habit` is unchanged (`id, title, categoryId, startDate, endDate, weekdays?, deletedAt?`).
`partitionHabits(habits): { active: Habit[]; archived: Habit[] }` treats `deletedAt !== undefined` as archived and sorts each list by `createdAt` then `title`.
`archiveHabit(id, archived)` sets/clears `deletedAt` and stamps `updatedAt`; restoring clears it. `habitApplies` already hides archived habits from ghosts — do not change it.

## Edge cases / must NOT change
- A habit whose category was archived still renders with its saved category name; it is not deleted.
- Archiving removes its future ghosts immediately (existing `habitApplies`); tasks already created from it stay.
- Restoring brings ghosts back only for days within `startDate`..`endDate` that match `weekdays`.
- Do NOT add a `version` bump or Zod migration; do NOT change `HabitSchema`, `ghostsFor`, `describeSchedule`, `CategoriesView`, or the add-task inline input.
- Do NOT remove the ghost "Edit habit" gear on the Day page.
